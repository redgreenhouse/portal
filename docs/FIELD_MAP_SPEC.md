# Especificación de campos

- Rosa: imagen.
- Amarillo: texto; se convierte en fecha cuando la etiqueta contiene “Fecha”.
- Verde: Datos Maestros.
- Azul cielo: estado exclusivo ✓ / ✗ / NL.
- Rojo: checkbox independiente, activo por defecto.

Las firmas variables no coloreadas no generan controles. Los nombres permanentes del director, responsable técnico y auxiliar SRRC se administran como Datos Maestros.
