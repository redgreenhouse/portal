# RELEASE V1.36

## Alcance

Corrección puntual del flujo de cabeceras y exportación Excel para M2–M7.

## Cambios funcionales

- M2 conserva los valores de cabecera, firmas y enlaces de evidencia después de restaurar las fórmulas de la plantilla.
- M2 evita el error `Cannot read properties of null (reading 'async')` al copiar dibujos del XLSX.
- M3–M7 reemplazan fórmulas externas de cabecera por Datos Maestros en la vista web.
- M3–M7 escriben Folio SENASICA, Emisión, Vigencia y Versión en el Excel descargado.
- Portal público y privado muestran la versión 1.36.
