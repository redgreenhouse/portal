# Público, privado y Google Drive

- La página pública se muestra primero.
- `Portal RED` abre el acceso privado.
- Contraseña inicial: `RED2026`. Cambiarla en Administración.
- Esta barrera es local y básica; no sustituye autenticación de servidor.
- En Administración se conserva el ID de la carpeta Images.
- `apps-script/Code.gs` es la base para desplegar el Web App que recibirá imágenes.
- Después de desplegar Apps Script, pegar su URL en Administración > Google Drive.
